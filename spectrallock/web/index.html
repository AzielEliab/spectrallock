Rosetta spectral analysis

SpectralLock is Rosetta spectral analysis software — the same SpectralLock lenses used by Aziel Corpus Library OCR (overlays, ink/page modes). RSA-2.0 decoding composite: 0.40·Z′ + 0.35·T′ + 0.25·V′. Balance never invents marks. Synthetic UV is a 365–400 nm look from an ordinary photograph. The human still reads the page. Author Aziel Eliab.
